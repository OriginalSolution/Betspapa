Every alert now names both clubs in full, for example "GOAL! Arsenal 1-0 Chelsea" with the scorer and minute when known. Kick-off, half-time, full-time, red card, penalty and VAR alerts read the same way, from server push and from the on-phone watcher on phones without Google Play services. The small notification card shows full names instead of short codes, and code and slip results list the real fixtures and scores.
